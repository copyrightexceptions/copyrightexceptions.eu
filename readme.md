# copyrightexceptions.eu

This project contains the code and data for the 2020 rebuild of the [copyrightexceptions.eu](https://copyrightexceptions.eu/) website. As of February 2021 the website architecture has been validated. 

We are currently in the process of adding data on the implementation of the CDSM and InfoSoc exceptions (for now the Marrakesh and Orphan Works directive exceptions are out of scope — they will be added at a later stage).

## Implementation Status

As of 7 May 2026, all EU27 Member State implementations (excluding the MKD, OWD, and info53o exceptions) are complete.
